はじめまして、「しがなし」です！  
この度、個人ブログ（技術ブログ）を始めました。

## ブログを始めた理由

本ブログの目的は「アウトプットの習慣をつける」ことです。  

転職活動をきっかけに、自身のアウトプットが足りていないことを痛感しました😭  
業務中は淡々とタスクをこなすことが多いため、自分で意識しなければ技術の整理やアウトプットをする機会はあまりないだろうと思い、ブログを始めてみることにしました。  

ポートフォリオ的な意味合いもありますが、記事を書くことで知識を定着させたり、自分の思考を整理したりできればいいなぁ…と考えています。

## なぜ自分でブログを作ったのか

Qiita や Zenn といったサービスがある中で、わざわざ自分でブログを立ち上げた理由は以下の通りです。

- サービスにあまり依存したくないため
  - AI 時代なので、一からブログを立ち上げるのもそこまで手間ではない
  - Markdown で手元に残しておけば、サービスに載せたくなっても引っ越しは楽なはず
- デザインやレイアウトなどの自由度が高いため
- 集客が主目的ではないため
  - 性格によるところが大きいですが、見られていないと思って書くほうが書き始めるのが早い

一方で、デメリットも少なからずあると考えています。

- 投稿した記事が読まれない可能性が高い
  - 内容が間違っていても指摘される機会が少なく、誤った理解のまま定着してしまうかも
- サービスを使うより運用が大変
  - これは技術や自動化でカバーしていく（それも技術習得になる）

## このブログの構成

以下の技術を用いています。

- Astro
- Cloudflare Workers
- GitHub

Cloudflare Workers と GitHub を連携させ、GitHub に push すると自動でビルド・デプロイされる形です。

### なぜ Astro？

Hugo や Gatsby といった似たようなツールも過去に使ったことがありますが、Astro が一番使い心地が良かったというのが大きな理由です。  
また、すでに慣れ親しんでいる React を使ってカスタマイズできるので、自分との相性も良いです。

加えて、Astro を最後に触ったのが数年前なので、最新の状況を把握したいという意味も込めて今回は Astro に決めました。

### なぜ Cloudflare Workers？

静的サイトのホスティング先としては Netlify や Vercel も候補でしたが、今回は Cloudflare Workers に決めました。

| | Cloudflare Workers（Free） | Netlify（Free） | Vercel（Hobby） |
|---|---|---|---|
| 転送量 | 静的アセットは無制限 | 20 クレジット/GB | 100GB/月 |
| リクエスト | 静的アセットは無制限<br>（Worker の実行は 10 万回/日） | 2 クレジット/1 万リクエスト | 100 万回/月 |
| ビルド・デプロイ | ビルド 3,000 分/月 | 本番デプロイ 1 回につき 15 クレジット | 時間の記載なし（Basic マシン） |
| 備考 | | 上記すべてで月 300 クレジットを共有 | 個人・非商用利用のみ |

Netlify はクレジット制になっており、月 300 クレジットを転送量やデプロイで分け合う形。  
ちょっと枠が心配ですね。

Vercel は転送量 100GB/月と十分ですが、Hobby プランは非商用利用に限られています。  
商用利用する予定は今のところ特にないですが、広告を載せたりしたくなったら変える必要が出てきます。  

Cloudflare Workers は、静的アセットへのリクエストが無料かつ無制限なので、ブログのような静的サイトであれば転送量を気にする必要がほぼありません。  
加えて、ドメインも Cloudflare でまとめて管理できるため、DNS からホスティングまで一か所で完結し、カスタムドメインの設定も楽です。
